# Shadow Impact: Brawler Arena

Subprojeto de luta arcade 2D/3D para o portal de jogos.

## Estrutura Planejada
- `combat/`: Deteção de hitboxes, hurtboxes, frames de invencibilidade e combos.
- `fighters/`: Definições de atributos, sprites/modelos e árvore de movimentos dos lutadores.
- `arena/`: Cenários com limites de tela e iluminação de combate.
- `ui/`: Barras de vida, medidores de especial (super meter) e indicador de combo.
