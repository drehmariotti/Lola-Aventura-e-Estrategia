# Cyber Sector: Orbital Assault

Subprojeto de tiro espacial e tático para o portal de jogos.

## Estrutura Planejada
- `weapons/`: Sistema de projéteis, lasers, cadência e recarga.
- `enemies/`: Comportamentos de drones, naves e chefes de setor.
- `particles/`: Explosões, feixes de plasma e faíscas.
- `ui/`: Mira HUD, radar de proximidade, munição e escudos.
