# Turbo Velocity: Apex Racing

Subprojeto de corrida arcade 3D para o portal de jogos.

## Estrutura Planejada
- `physics/`: Simulação de aceleração, frenagem, aderência e drift.
- `tracks/`: Definição de circuitos, waypoints e checkpoints de tempo.
- `renderer/`: Cena 3D Three.js com veículo, iluminação e efeitos de velocidade/fumaça.
- `ui/`: Velocímetro, tacômetro, minimapa e tempos de volta.
